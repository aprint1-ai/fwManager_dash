# fwManage_dash (푸드윈 통합 관리 대시보드)

`fwManage_dash`는 푸드윈 및 군포 센터의 매출, 물류, 품목 재고 관제를 위해 새로 구성된 React + Vite 대시보드 프로젝트입니다.

## 🚀 주요 기능
- **종합 현황 관제**: 주요 KPI (누적 총 실적, 목표 달성률, 품목 수, 재고 알림) 및 차트
- **사업부별 추이 분석**: 푸드윈, 파인쿡, 군포센터별 월간 매출액 및 누적 통계 그래프 (Recharts)
- **품목 및 지표 관리**: 신규 품목 등록/삭제, 카테고리 필터링, 검색 기능

## 🛠️ 실행 방법
1. 의존성 패키지 설치:
   ```bash
   npm install
   ```
2. 개발 서버 실행:
   ```bash
   npm run dev
   ```
3. 브라우저에서 `http://localhost:5173` 접속
